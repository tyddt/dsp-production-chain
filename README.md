# 戴森球计划 · 生产链求解器

输入一个目标产物和它的速率，递归展开整条生产链：每一级要多少物料、几台设备、几条传送带、多少电，
并自动标出副产物配平、取整过剩和潜在瓶颈。

## 使用

**双击 `index.html` 即可。** 单文件、零依赖、配方数据全部内嵌，不需要安装任何环境。

- 首次打开时物品图标需要联网（从 dsp-wiki 按需加载），加载失败会自动回退成该物品的官方代表色块
- 状态自动保存在浏览器 local storage，关掉再打开会恢复上次的产物、参数和配方选择

## 界面

**左侧参数面板**（改任意一项立刻重算）

- 设备等级：制造台 / 熔炉 / 化工厂 / 矩阵实验室 / 传送带
- 增产剂：不使用 / Mk.I~III 加速 / Mk.I~III 增产，外加「增产剂自喷涂」开关
- 分馏模型：循环带几何衰减（推荐）/ 线性近似 / FactorioLab 口径，转化率、氢堆叠层数、是否给氢喷增产剂可调
- 取整传播：按理论需求（不膨胀）/ 按实际产能（层层放大）
- 终止层：勾选哪些物品算「外购」，到这层就不再往下展开

**右侧结果**

| 区块 | 作用 |
|---|---|
| 体检结论 | 自动列出副产物净剩、满载率过低、需带数过多的节点 |
| 生产树 | SVG 横向树，节点上是物品、设备和台数，连线上标每秒流量；点节点看该物品的全部配方 |
| 设备汇总 | 各设备总台数、喷涂需求、总功耗 |
| 中间产物总需求 | 把树上分散的同名物品合并成一条产线的总量，附「被几个环节消耗」 |
| 外购 / 终止层需求 | 要外部输入的物料清单，含需几条满带 |
| 副产物配平 | 多输出配方的副产物净流量，净剩为正就意味着会堵线 |
| 取整过剩 | 设备向上取整产生的过剩产能与满载率 |

**遇到有多种合成路线的物品**（重氢、氢、石墨烯、金刚石、卡西米尔晶体等）会弹窗让你选路线，
每条路线会标出输入输出、耗时、是否为采集类、是否被数据集默认排除。选过的会被记住。

## 已知限制

影响最大的几条：

- **分拣器吞吐与物流塔吞吐不在模型内。** 这两项经常才是真正的限速环节，台数算对了也可能喂不饱
- **0.10.29 起原料自动化缓存机制有变**，会让实际满载率低于理论值，建议按理论值 ×0.9~0.95 使用
- 采矿机 / 抽水机 / 采油机在数据源里没有功耗字段，未计入耗电
- 设备台数一律向上取整，过剩量与满载率在「取整过剩」表中列出
- 数据集版本为 `0.10.29.21950`，已逐条核对更新日志确认到 `0.10.34` 无配方数值改动；
  游戏后续若大改配方，需要重新获取数据

**如果算出来的台数与游戏内实测不符**，先看设备速度倍率：制造台 Mk.I / II / III 是 **0.75 / 1 / 1.5**，
网上流传的 1 / 1.5 / 2 是错的，按后者算全部台数会少 25%。

游戏自带核对工具：0.10.31 起「分析面板 → 生产统计」会显示理想功率下的参考速率，可直接与本工具对照。
